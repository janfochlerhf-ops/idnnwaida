# 🎩 Mafia Reborn Bot

Autonomní asistent a bot pro webovou hru [Mafia Reborn](https://mafiareborn.com).

## 🚀 Funkce
- **Kmotr (Mise):** Automatický výběr a plnění nejvýhodnějších úkolů podle XP a odměn.
- **Aréna přežití (Survival):** Boj ve vlnách s odměnami zdarma.
- **PvP Duely:** Výběr vhodných protivníků s nulovými náklady.
- **Policie & SWAT:** Automatické souboje při policejním přepadení pro zisk odznaků a bonusů.
- **Smart-Skills:** Inteligentní vylepšování statistik s finanční rezervou.
- **Režim učení (Learn Mode):** Pasivní záznamník lidského hraní pro analýzu hry a vývoj nových modulů.
- **Vzdálený Auto-Update:** Automatická aktualizace kódu přímo z tohoto repozitáře.

## 📦 Požadavky
- Python 3.10+
- Knihovny: `pip install -r requirements.txt`
- Prohlížeč: `playwright install chromium`

## 🖥️ Spuštění
- Grafické rozhraní: `python gui_app.py`
- Terminál: `python mafia_bot.py`
